# RianTool · Flashcard

作为一名学生，我找了很多背单词软件，要么特别难用，要么要花钱，我干脆自己用ai做了一个。

一个本地运行的背单词卡片工具，单 HTML 文件，浏览器直接打开即用。专为 SAT/TOEFL 等考试词汇设计。

## 功能

- **词表管理**：文件夹 → 词表 → 单词三级结构，支持自定义命名、排序、CSV 批量导入
- **背单词卡片**：两步确认模式（先猜认识/不认识 → 显示释义 → 再确认），支持键盘左右键操作
- **难词本**：选「不认识」自动归入难词本，星级系统（1-5星），按星级排序和筛选
- **抽词模式**：自定义范围、数量（10/20/50/自定义），结束后可重背错词
- **预览与编辑**：快速查看词表内容，直接点击编辑单词和释义，支持批量多选删除
- **数据本地存储**：通过 File System Access API 指定本地文件夹保存数据，方便跨设备同步
- **暗色模式**：亮色 / 暗色 / 自动跟随系统
- **批量粘贴导入**：从 Excel 直接复制两列粘贴，自动识别逐行添加

## 使用

1. 下载 `背单词卡片.html`
2. 双击用 Chrome / Edge 打开
3. 首次使用建议在「设置 → 数据」中连接数据文件夹，所以请创建一个文件夹共数据收容使用，而后续添加词汇时数据会保存在该文件夹的 `vocab-data.json` 中
